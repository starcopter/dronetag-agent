# Technical Documentation

This section contains technical documentation for the Dronetag Agent and related components.
Its target audience can be split into two groups:

1. Developers who want to understand the internals of the implementation
2. Third parties who need to assess the design (e.g. Notified Bodies)

It is structured as follows:

- [EN 4709-002](en4709-002/index.md) requirements, along with notes on the implementation and applicability of the requirements
- a [Message Directory](messages/index.md) containing relevant MAVLink messages and details on the implementation
- a section detailing the [Operational Status](operational-status/index.md), including information about different emergency scenarios
