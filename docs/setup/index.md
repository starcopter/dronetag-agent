# System Setup

To integrate a Dronetag DRI module with a HIGHDRA, both the module and the Skynode need to be configured first.

1. [Configure the DRI module](dri-module.md)
2. [Prepare the Skynode](skynode.md), both PX4 and AuterionOS
3. [Install the Dronetag Agent](dronetag-agent.md)

Be aware that the [AuterionOS modifications](skynode.md#auterionos-configuration) need to be repeated after each AuterionOS update!
